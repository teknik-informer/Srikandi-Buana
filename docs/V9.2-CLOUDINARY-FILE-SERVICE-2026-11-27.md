# V9.2 — Layanan Berkas Terpusat (Cloudinary)

Tanggal: 27 November 2026  
Branch: `feat/v9.2-production-integration`

## Tujuan dan batas arsitektur

Srikandi Buana menggunakan satu layanan berkas lintas aplikasi. Cloudinary menjadi media/object storage; Neon tetap menjadi sumber kebenaran untuk organisasi, pemilik, lingkup akses, metadata, status, audit, relasi dokumen, dan izin. Kode aplikasi tidak menyimpan URL Cloudinary langsung pada halaman klien.

Setiap unggahan dibuat sebagai **authenticated asset**. Backend membuat delivery URL bertanda tangan menggunakan secret Cloudinary hanya setelah pemeriksaan izin aplikasi. Browser hanya menerima URL endpoint aplikasi Srikandi Buana, bukan API secret atau URL delivery internal Cloudinary.

## Cakupan yang sudah disiapkan

- API unggah: `POST /api/files`.
- API unduh/pratinjau: `GET /api/files/:id`.
- Pembuatan dan pencabutan tautan: `POST|DELETE /api/files/:id/share`.
- Pengambilan melalui tautan berbagi: `GET /api/files/share/:token`.
- UI Pusat Berkas: `/app/berkas`.
- Pratinjau dan cetak berkas PDF/gambar: `/app/berkas/:id`.
- Komponen bersama: `FileUploadField` dan `FileShareButton`.
- Aplikasi Sekretariat sudah memakai komponen unggah dan menyimpan referensi aset Cloudinary di tabel revisi dokumen.
- Dokumen lama yang masih memiliki `file_data` bytea di Neon tetap dilayani oleh endpoint Sekretariat lama sebagai jalur kompatibilitas.

Layanan dan komponen tersebut menjadi pola standar yang dapat dipakai modul lain. Formulir operasional yang belum diubah masih perlu dihubungkan satu per satu sesuai jenis lampirannya; dokumen Sekretariat adalah konsumen lintas-modul pertama yang telah dipasang.

## Format dan batas unggahan

Batas awal mengikuti kompatibilitas aplikasi yang ada: **3 MiB per berkas**. Format:
- PDF
- JPG/JPEG, PNG, WEBP
- DOCX, XLSX, PPTX
- MP4

Backend memvalidasi MIME, ukuran, signature berkas, dan nama berkas. Berkas office dan PDF dikirim sebagai raw asset dengan ekstensi yang ikut menjadi bagian public ID sesuai persyaratan Cloudinary; gambar memakai resource type image dan video memakai video.

Pratinjau/cetak di browser disediakan untuk PDF dan gambar. DOCX/XLSX/PPTX/MP4 tersedia untuk diunduh; konversi Office-to-PDF belum menjadi bagian tahap ini. Dokumen hasil generator Sekretariat tetap menggunakan halaman cetak dokumen yang sudah ada.

## Hak akses

- Metadata aset diberi `organization_id`, pengunggah, kategori, dan lingkup `self`, `field`, atau `organization`.
- Permintaan baca/unduh harus melewati pemeriksaan identitas, organisasi, lingkup, dan permission.
- Lampiran dokumen Sekretariat yang belum final, internal, terbatas, atau telah diarsipkan tidak bisa diambil lewat endpoint publik Pusat Berkas.
- Endpoint Sekretariat mempertahankan aturan akses terdahulu, termasuk unduhan anonim hanya untuk dokumen berstatus final dan visibilitas publik.
- Token berbagi acak 256-bit; database hanya menyimpan SHA-256 token, bukan token aslinya.
- Pemilik berkas dapat melihat status, masa berlaku, jumlah unduhan, dan mencabut tautan aktif. Token lama tidak dapat diambil ulang karena tidak disimpan dalam bentuk terbuka.
- Link yang merujuk pada dokumen Sekretariat akan ditolak ketika dokumen bukan final-publik atau bukan revisi terkini.
- Tautan berbagi default berlaku 7 hari; masa berlaku dibatasi 1–30 hari, unduhan opsional 1–1.000 kali; tautan dapat dicabut.
- Setiap unggah dan pembuatan/pencabutan tautan menulis audit event.
- POST/DELETE memeriksa origin untuk mengurangi risiko CSRF.

## Konfigurasi deployment yang diperlukan

Audit environment Vercel untuk project `admin-dashboard` tidak menemukan variabel Cloudinary. Aplikasi memerlukan tiga variabel server-side berikut:

- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`

Untuk URL berbagi, gunakan host deployment yang tepat: `VERCEL_URL` untuk Preview dan `APP_URL` sebagai alamat kanonis aplikasi. Tambahkan variabel Cloudinary pada Vercel **Preview untuk branch `feat/v9.2-production-integration` saja** saat pengujian disetujui. Jangan menambahkan ke Production tanpa persetujuan terpisah. Jangan memasukkan secret ke source code, file `.env` yang dikomit, atau percakapan.

Folder akar `srikandi-buana` sudah dibuat pada Cloudinary. Upload aplikasi akan memakai subfolder per organisasi: `srikandi-buana/{organization_id}`.
